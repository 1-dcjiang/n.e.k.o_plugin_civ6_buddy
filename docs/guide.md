# 文明6陪玩（civ6_buddy）使用说明

让 YUI 陪玩家打《文明6》：通过解析本地 `.Civ6Save` 存档获知当前局面，并给出陪玩建议。

## 它能做什么

- **看懂局面**：回合数、游戏速度、地图大小与类型、你的文明与领袖（含特性一句话）、全部敌对文明与领袖、城邦列表、已装 MOD。
- **给建议**：开局 / 科技 / 建城 / 战争 / 胜利路线 / 外交，按当前局面分主题给出规则化陪玩建议。
- **只读不写**：不修改存档、不写任何游戏文件。

## 怎么用

对桌面 YUI 说，例如：

- 「看一下我文明6的存档，现在什么局面？」
- 「我这局用什么路线好？」
- 「先推荐一个文明6的开局科技路线」
- 「我现在的对手都有谁？」

YUI 会自动调用插件工具：列出存档 → 解析最新存档 → 汇报局面 → 给建议。

## 存档目录

默认读取：

```
C:\Users\<用户名>\Documents\My Games\Sid Meier's Civilization VI\Saves
```

可在插件运行配置 `config\plugin.toml` 的 `[civ6_buddy]` 节中改 `saves_dir` 覆盖。

## 运行依赖

- 本机安装 Node.js（>=16）：解析器内嵌于插件包，通过 `node` 执行。
- 游戏本体《Sid Meier's Civilization VI》（本地路径检测不依赖游戏运行中）。

## 进阶版：运营托管（v0.2.0，屏幕自动化）

分工规则：**运营归 YUI，打仗归你**。YUI 按"推荐制"执行运营——只点游戏内固定按钮/推荐项目，不做单位移动、不碰战斗、不碰外交。

**使用方式**（游戏内，对桌面 YUI 说）：

1. 「**接管运营**」→ 进入运营托管（记录当前回合）
2. 「**继续**」→ 执行本回合运营：定位游戏窗口 → 处理弹窗 → 点下一回合 → 等待结算
3. 「**我来打**」/「停止托管」→ 立即交还控制权（检测到战争横幅也会自动交还）

**能力边界（如实说明）**：
- 执行层复用 steam_manager 现成键鼠操控（YUI 的键鼠控制），steam_manager 未安装时回退 pyautogui
- 弹窗处理用 ESC 清扫（文明6 ESC 只关面板，无副作用）；连续弹窗无法清除会停止并交还
- 城市生产走游戏自带"推荐建造"按钮；**科技树没有推荐按钮，科技研发留给你**（YUI 给建议）
- 每次操作前截图验证，识别不了就停下如实汇报，**绝不猜点**
- 不改存档、不读内存

**按钮坐标校准**：默认"下一回合"坐标按 1920x1080 窗口实测。分辨率不同时在运行配置 `[civ6_buddy.ops_buttons]` 中校准（见 config.example.toml 注释）。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 「尚无任何存档」 | 游戏还没自动存档：开局后等 AutoSave 生成再问 |
| 「本机没有 node」 | 安装 Node.js（https://nodejs.org）后重启插件 |
| 「解析失败」 | 存档损坏或版本不兼容：换个存档试 |
